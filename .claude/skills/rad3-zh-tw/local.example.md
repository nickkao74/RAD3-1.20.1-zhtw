# 本機路徑設定（範本）

複製成同資料夾的 `local.md` 後，改成你自己電腦上的路徑。`local.md` 已被 gitignore，不會進版控。
skill 與子代理文件中的 `<實例>`、`<原版語言檔>` 都以此檔為準。

- `<實例>`（模組包實例資料夾，唯讀，取 mods jar 與 config 用）：
  `C:/path/to/Roguelike Adventures and Dungeons 3`
- `<原版語言檔>`（Minecraft 1.20.1 原版 zh_tw 語言檔，JSON）：
  `C:/path/to/.minecraft/assets/objects/ea/ea26c1cee4ef2006eb3ac010b8489399ff6e5639`
  （檔案名是 assets index 中 `minecraft/lang/zh_tw.json` 的 hash；不同啟動器的 assets 資料夾位置不同）
